# tel-aviv-money-game

משחק החלטות בתל אביב: 300 אלף שקל ב-2005, 21 תורות עד 2026.

**הערת נתונים:** מחיר הדירה במשחק הוא פרוקסי של דירת 80 מ"ר לפי מחירי מ"ר בנחלת יצחק. זה אינו מדגם עירוני של תל אביב-יפו. השנים 2005–2009 הן השלכה מודלית לאחור, ולא נתוני עסקאות. המקורות והנחות החישוב מופיעים בדף המשחק.
